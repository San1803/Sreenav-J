# Sreenav J — Personal Portfolio

A responsive, self-contained portfolio built with HTML, CSS and vanilla JavaScript. No frameworks, build tools or API keys required.

## Run locally
Open `index.html` in any modern browser. For local server testing, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Personalize before publishing
1. Edit the `PROFILE` object at the top of `script.js` to add your real email, LinkedIn, and GitHub URL. Links appear automatically only when configured. These details were not provided in the résumé.
2. Check all role descriptions, employment dates, and project descriptions to ensure you're comfortable sharing them publicly. They were adapted from the supplied résumé; project graphics are conceptual and do not expose private client work.
3. The downloaded résumé lives at `assets/Sreenav_J_Resume.docx`. Replace this file whenever you update your résumé.
4. Optional: replace the abstract hero artwork with your own photo or illustration; the page works without any photos.

## Publish
Upload the contents of this folder to Netlify, GitHub Pages, Cloudflare Pages or another static hosting provider. No server-side code is required.

## Files
- `index.html` — semantic site structure and content
- `styles.css` — responsive design and motion
- `script.js` — filtering, mobile navigation, contact links and reveal effects
- `assets/Sreenav_J_Resume.docx` — original résumé supplied for the site

## Accessibility
Includes a skip link, semantic landmarks, keyboard-friendly navigation and filters, and reduced-motion handling.
